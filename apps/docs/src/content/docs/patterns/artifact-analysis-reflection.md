title: Artifact Analysis Reflection
description: A research and evaluation pattern for analyzing existing artifacts using a structured rubric and reflective writing.
---

**Pattern ID:** `artifact-analysis-reflection`

**Best for:** Research courses, portfolio review, learning outcome assessment, AIUL impact studies, capstone evaluation.

## Sequence

### 1. Artifact Selection
Select or receive an artifact for analysis.

### 2. Structured Analysis
Apply a rubric or analytical framework to the artifact.

### 3. Written Reflection
Write a reflection on the analysis, connecting findings to broader learning.

## Assessment Evidence
- Analyzed artifact
- Coded rubric or analysis notes
- Reflection
- (Optional) Evaluator notes
