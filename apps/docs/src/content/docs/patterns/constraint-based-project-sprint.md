---
title: Constraint-Based Project Sprint
description: A fast creative production pattern using explicit constraints to focus and challenge learners.
---

**Pattern ID:** `constraint-based-project-sprint`

**Best for:** Fast production cycles, creative constraints, portfolio development, game jams, hackathons, design sprints.

## Sequence

### 1. Constraint Introduction
Define the project constraints (time, tools, theme, scope, medium).

### 2. Sprint Production
Produce an artifact within the defined constraints.

### 3. Critique and Review
Share and critique completed projects.

## Assessment Evidence
- Project artifact
- Process log
- Critique notes
