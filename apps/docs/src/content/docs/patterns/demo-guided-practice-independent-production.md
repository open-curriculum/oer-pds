title: "Demo → Guided Practice → Independent Production"
description: A technical skill-building pattern that moves from instructor demonstration through guided practice to independent work.
---

**Pattern ID:** `demo-guided-practice-independent-production`

**Best for:** Software tutorials, technical workflows, tool-based learning, coding, 3D modeling, animation techniques.

## Sequence

### 1. Demo
Instructor demonstrates the skill or process in full.

- **Learner:** Watches demonstration, takes notes, asks questions
- **Instructor:** Demonstrates the complete process, narrates decisions
- **Evidence produced:** Notes, questions

### 2. Guided Practice
Learner replicates the process with real-time support.

- **Learner:** Follows along with the demonstration, completing each step
- **Instructor:** Monitors progress, provides immediate correction
- **Evidence produced:** Practice exercise

### 3. Independent Production
Learner applies the skill to a new, slightly varied task without guidance.

- **Learner:** Completes an independent exercise using the demonstrated skill
- **Instructor:** Reviews completed work, provides feedback
- **Evidence produced:** Independent exercise, short reflection or skill checklist

## Assessment Evidence
- Completed guided exercise
- Independent exercise
- Process screenshots or recording
- Short reflection or self-assessment checklist
