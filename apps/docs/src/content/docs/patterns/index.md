Instructional patterns are reusable sequences of learning activity.

Like design patterns in software, each pattern describes a recurring problem, the context in which it appears, the sequence of actions that address it, the evidence it produces, and the consequences of using it.

## How Patterns Work

A pattern is not a rigid script. It is a **sequence of phases**, each with:

- A **learner action** — what the student does
- An **instructor action** — what the teacher or facilitator does
- **Evidence produced** — what comes out of this phase that can be assessed

Patterns are **combined with themes and tokens** to produce the full instructional profile of a learning experience.

## Choosing a Pattern

Use this decision table:

| Learning goal | Recommended pattern |
|---------------|-------------------|
| Build creative judgment + artifact | [Observe → Analyze → Create → Critique → Revise](/patterns/observe-analyze-create-critique-revise/) |
| Develop technical skill | [Demo → Guided Practice → Independent Production](/patterns/demo-guided-practice-independent-production/) |
| Analyze a case or scenario | [Case → Stakeholder Analysis → Response Design](/patterns/case-stakeholder-analysis-response-design/) |
| Develop AI literacy | [Prompt → AI Experiment → Evaluate → Disclose](/patterns/prompt-ai-experiment-evaluate-disclose/) |
| Combine reference + technical + creative | [Reference Study → Technical Exercise → Creative Application](/patterns/reference-study-technical-exercise-creative-application/) |
| Fast creative production | [Constraint-Based Project Sprint](/patterns/constraint-based-project-sprint/) |
| Iterative collaborative making | [Peer Review Studio Cycle](/patterns/peer-review-studio-cycle/) |
| Self-paced competency | [Mastery Checkpoint Pathway](/patterns/mastery-checkpoint-pathway/) |
| Portfolio or research review | [Artifact Analysis Reflection](/patterns/artifact-analysis-reflection/) |
| Community-engaged design | [Community-Contextualized Design Brief](/patterns/community-contextualized-design-brief/) |
