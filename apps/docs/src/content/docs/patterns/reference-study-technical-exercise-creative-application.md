---
title: "Reference Study → Technical Exercise → Creative Application"
description: A three-stage pattern that moves from studying references through technical skill practice to creative production.
---

**Pattern ID:** `reference-study-technical-exercise-creative-application`

**Best for:** Visual design, 3D modeling, animation principles, motion graphics, illustration, media production.

## Sequence

### 1. Reference Study
Analyze examples of the technique or style being studied.

- **Learner:** Collects and analyzes references, identifies key techniques
- **Evidence produced:** Reference analysis notes or moodboard

### 2. Technical Exercise
Practice the isolated technical skill in a constrained exercise.

- **Learner:** Completes a technical exercise focused on one aspect of the reference
- **Evidence produced:** Technical exercise artifact

### 3. Creative Application
Apply the technique in an open creative project.

- **Learner:** Produces a creative artifact using the practiced technique with their own creative choices
- **Evidence produced:** Creative artifact, brief reflection on how the technique was applied

## Assessment Evidence
- Reference analysis
- Technical exercise
- Creative artifact
