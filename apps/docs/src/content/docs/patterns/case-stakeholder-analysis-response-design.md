**Pattern ID:** `case-stakeholder-analysis-response-design`

**Best for:** Communication, public relations, ethics, organizational change, health communication, policy, social design.

## Sequence

### 1. Case Introduction
Present a complex real or realistic scenario with multiple stakeholders.

- **Learner:** Reads and analyzes the case, identifies key issues
- **Instructor:** Provides case context, frames analytical questions

### 2. Stakeholder Analysis
Map the perspectives, interests, and constraints of each stakeholder.

- **Learner:** Completes a stakeholder matrix or analysis worksheet
- **Instructor:** Facilitates discussion of competing perspectives

### 3. Response Design
Design a strategic, evidence-based response to the case scenario.

- **Learner:** Produces a strategy memo, communication plan, or design brief
- **Instructor:** Reviews for stakeholder alignment and strategic reasoning

### 4. Debrief
Compare and evaluate different response designs.

- **Learner:** Presents or shares response, discusses tradeoffs
- **Instructor:** Facilitates debrief, surfaces key tensions

## Assessment Evidence
- Stakeholder matrix
- Strategy memo or response design
- Debrief notes or reflection
