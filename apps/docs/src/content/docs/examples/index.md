The flagship demonstration of OIS is simple:

> **Same content. Four pedagogical styles.**

OIS examples show how a single content object — the same learning objectives, the same subject matter — can be structured as completely different learning experiences by applying different themes, patterns, and tokens.

## Flagship Example: Camera Framing in 3D Animation

This example uses a lesson on camera framing in 3D animation rendered four ways:

| Style | Theme | Pattern |
|-------|-------|---------|
| [Direct Instruction](/examples/camera-framing-direct-instruction/) | `direct-instruction` | `demo-guided-practice-independent-production` |
| [Constructivist Studio](/examples/camera-framing-constructivist-studio/) | `constructivist-studio` | `observe-analyze-create-critique-revise` |
| [Critical Media Analysis](/examples/camera-framing-critical-media-analysis/) | `critical-media-analysis` | `case-stakeholder-analysis-response-design` |
| [Mastery Pathway](/examples/camera-framing-mastery-pathway/) | `mastery-learning` | `mastery-checkpoint-pathway` |

Each version shows:
- The content object (same for all four)
- The applied tokens
- The student-facing output
- The instructor-facing notes
- The assessment evidence
- The validation report
- The AI-readable JSON
