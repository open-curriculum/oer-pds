## 0.1.0-alpha

*Initial public alpha.*

### Added
- 10 pedagogical token groups: `scaffolding`, `agency`, `feedback`, `assessment`, `revision`, `reflection`, `collaboration`, `accessibility`, `localization`, `aiUse`
- 10 instructional patterns
- 10 pedagogical themes
- 7 renderer profiles
- Starter validation rules (alignment, AI use, accessibility, agency/scaffolding)
- JSON Schemas for all entity types
- `llms.txt` and `llms-full.txt` for AI agent discovery
- `ois-index.json` machine-readable registry
- OERSchema mapping table
- JSON-LD context file

### Notes
This is a public alpha. The vocabulary is usable and stable enough for experimentation and implementation. Breaking changes to token IDs are not expected after 0.1.0 final.

Community feedback is welcome via GitHub Issues at [github.com/open-curriculum/oer-pds](https://github.com/open-curriculum/oer-pds).
